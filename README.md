# Marketing Campaign Exploratory Data Analysis (EDA)

## 📖 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Marketing Campaign dataset to understand customer behavior, analyze marketing channel performance, and provide business recommendations based on the findings.

## 🎯 Objective

Perform EDA to identify customer trends and recommend which marketing channels should receive more budget based on Return on Investment (ROI).

## 🛠 Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Analysis Performed

- Data Cleaning
- Missing Value Analysis
- Duplicate Check
- Income Distribution
- Education Analysis
- Marital Status Analysis
- Marketing Channel Performance
- Campaign Acceptance Analysis
- Customer Age Distribution

## 📂 Repository Contents

- task4_eda.ipynb
- summary_report.pdf
- Demo Video
- README.md

## 📌 Key Insights

- Store purchases generated the highest customer engagement.
- Web purchases showed strong performance and growth potential.
- Catalog purchases contributed comparatively less.
- Marketing campaigns varied significantly in customer acceptance.

## 💡 Business Recommendation

Based on the analysis, increasing investment in **Web** and **Store** marketing channels is recommended due to higher customer engagement and purchase activity. Catalog marketing should be reviewed and optimized to improve ROI.
